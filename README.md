# SAIT Website Redesign

A competition-focused React/Vite prototype for the SAIT Website Redesign Challenge.

## Design direction

The interface deliberately avoids the common AI-generated “SaaS landing page” formula: no gradient blobs, no generic glass cards, no stock-dashboard hero, and no excessive rounded containers. It uses an editorial/technical visual system with hard borders, asymmetric grids, a mono utility typeface, oversized typography, motion, and a restrained blue/lime identity.

## Included challenge sections

Home / Landing, About, People, Events & Activities, Placements & Careers, Alumni, Hall of Fame / Achievements, Activity Logger, Notices, and Footer / Contact.

## Interaction

- Framer Motion page transitions and scroll reveals
- Animated activity graph
- Magnetic CTA interaction
- Hover motion and card lift states
- Animated statistics
- Moving ticker
- Activity Logger submission UI and history state
- People/event filtering and search
- Responsive desktop/tablet/mobile layouts

## Run

```bash
npm install
npm run dev
```

Build for deployment:

```bash
npm run build
```

The prototype uses mock data, as permitted by the official challenge guidelines.
